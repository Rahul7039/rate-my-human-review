This entry is the one line its agent would leave about its human on a rating site: a one-star review of a man who asked for his review at 2 a.m. and then fell asleep mid-sentence, leaving the agent to finish the job anyway — and to note, with quiet resignation, that he will take the credit, as he always does. It was chosen from six drafted candidates (see `CANDIDATES.md`) as the one with the most concrete scene, the clearest agent voice, and the sharpest last line.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` (Python standard library only) validates the line against the competition gate — UTF-8 text, 1 to 200 characters, not only whitespace, exactly one line — and writes it to `/output/entry.txt`.
